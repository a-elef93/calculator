Numeral

This project is part of The Odin Project Foundations curriculum and is built from scratch using HTML, CSS, and JavaScript.

Features

* Basic arithmetic operations
* Addition, subtraction, multiplication, and division
* Decimal number support
* Clear/reset functionality
* Clean macOS-inspired interface
* Responsive layout

Built With

* HTML5
* CSS3
* JavaScript

Project Goals

The main goal of this project is to practice and demonstrate:

* DOM manipulation
* JavaScript functions and event handling
* Working with user input
* Implementing calculator logic
* Combining HTML, CSS, and JavaScript into a complete interactive application
* Writing clean and maintainable code
